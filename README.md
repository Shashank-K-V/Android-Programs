# Android Program Examples

A collection of introductory Android exercises covering common platform capabilities. Each
text file contains a focused example that can be adapted inside an Android Studio project.

## Included examples

- Broadcast receivers
- Content providers and content resolvers
- Local database access
- File creation
- JSON handling
- Notifications
- Phone dialer intents
- Text-to-speech
- Simple counter application

## How to use

1. Create an Android Studio project for the example you want to try.
2. Copy the relevant Java/XML snippets from the matching text file.
3. Add any permissions named by the example to `AndroidManifest.xml`.
4. Run it on an emulator before testing on a physical device.

> These are learning references rather than a single buildable Android application. Android
> APIs and permission requirements may need small updates for current SDK versions.
